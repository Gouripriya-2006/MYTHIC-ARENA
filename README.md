# MYTHIC-ARENA
### Where Your Voice Controls Destiny

**Project:** AI-Powered Voice-First RPG  
**Challenge:** Gnani AI – Great Indian AI Internship Challenge 2026

### 1. Problem Statement

Traditional role-playing games primarily depend on keyboard, mouse, and controller-based interactions. This can limit natural interaction between players and game environments. There is an opportunity to make gaming more immersive and interactive through AI-powered voice technology.

### 2. Proposed Solution

MYTHIC-ARENA is an AI-powered role-playing game that combines immersive 2D and 3D gameplay with natural voice interaction. Inspired by Indian mythology, fantasy, and science fiction, the game takes players on an adventure through a fictional world called *The Lost Kingdom*.

Players can explore the environment, interact with characters, fight enemies, complete quests, and control selected gameplay actions using voice commands.

### 3. AI Integration and Workflow

The project integrates three key AI technologies:

- **Gnani AI Prisma STT:** Converts player speech into text.
- **Groq:** Interprets natural-language commands and identifies intended game actions.
- **Gnani AI Timbre TTS:** Generates spoken responses for an interactive experience.

**Workflow:**

Microphone → Prisma STT → Groq Reasoning → Intent Validation → Game Action Dispatcher → Game Execution → Timbre TTS.

The validated action system ensures that AI-interpreted commands are checked before execution within the game.

### 4. Key Features

- Interactive 2D gameplay using Phaser.
- Immersive 3D gameplay using Babylon.js.
- Voice-controlled interactions and combat.
- Warrior, Mage, and Guardian character classes.
- Enemy AI and multi-phase Ravana boss battle.
- Inventory, equipment, skill tree, and quest systems.
- NPC interactions and merchant system.
- Audio effects and gameplay progression.

### 5. Technology Stack

JavaScript, HTML, CSS, Phaser, Babylon.js, Node.js, Gnani AI Prisma STT, Gnani AI Timbre TTS, Groq, Git, and GitHub.

### 6. Expected Impact

MYTHIC-ARENA demonstrates how speech recognition, AI reasoning, and speech synthesis can be combined with game development to create a more natural and engaging gaming experience. It explores voice-first interaction as an additional way for players to control and experience role-playing games.
